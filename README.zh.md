# RuyiRepo

面向 RISC-V 的开源制品仓库，实现 RISC-V 生态软件可靠供给。

## Usage

### PyPI

地址:

```bash
https://ruyirepo.ruyicommunity.cn/pypi
```

用例:

```bash
pip install -i https://ruyirepo.ruyicommunity.cn/pypi/simple/ torch==2.10.0
```

[已支持的软件](./data/pypi.md)
